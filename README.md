The code for all experiments can be found in this repository.

## Installation

Follow the installation instructions in the golden-standard and OGBench folder for respective experiments. For the lightsout experiments, the same packages as the golden-standard experiments will work. So one could use the same environment.

To run the boxpick experiments, checkout golden-standard folder. The IRU agent name is dqn_interp.

To run the lightsout experiments, checkout the lightsout folder. The IRU agent can be run by settig architecture_type to int_thinker.

To run the OGBench experiments, checkout the OGBench folder. The IRU agent name is gciql_interp.
